# Spinna

## Description

Spinna is an open-source NEC and Sharp retro computer/console emulator frontend for Android based on Libretro.

### Supported Systems:
- NEC PC-8801 (quasi88)
- NEC PC-9801 (np2kai)
- NEC PC Engine / TurboGrafx-16 (beetle_pce core)
- NEC PC Engine CD (beetle_pce core)
- NEC PC Engine SuperGrafx (beetle_supergrafx core)

### Features:
- Android TV support
- Automatically save and restore game states.
- ROMs scanning and indexing
- Optimized touch controls
- Quick save/load
- Support for Zipped ROMs
- Display simulation (LCD/CRT)
- Gamepad support
- Local multiplayer
- Tilt input
- Customizable touch controls (size and position)
- Cloud save sync
- HD mode
